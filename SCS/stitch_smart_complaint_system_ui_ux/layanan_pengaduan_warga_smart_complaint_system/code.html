Pertanyaan Umum (FAQ)

Berapa lama laporan ditindaklanjuti? expand_more

Sesuai SPM (Standar Pelayanan Minimal), verifikasi data awal selesai dalam 1x24 jam. Penanganan fisik ke lokasi oleh tim Dinas PUPR ditindaklanjuti maksimal 3x24 jam hari kerja.

Bagaimana jika jalan rusak statusnya Jalan Provinsi atau Nasional? expand_more

Sistem LaporBDL terhubung langsung dengan SP4N-LAPOR! Nasional dan Dinas BMBK Provinsi Lampung. Laporan akan otomatis diteruskan secara resmi ke instansi yang berwenang.

Bagaimana cara memantau progres perbaikan jalan? expand_more

Setelah formulir dikirim, Anda akan mendapatkan Kode Tiket unik via SMS/WhatsApp dan dapat memantau linimasa kerja teknisi secara live di menu Antrean OPD.
